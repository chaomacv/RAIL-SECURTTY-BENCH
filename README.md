
RAIL-SECURTTY-BENCH is a domain-specific evaluation benchmark tailored for railway infrastructure security.

- [Project overview and benchmark](https://chaomacv.github.io/RAIL-SECURTTY-BENCH/)
- [Interactive Data Engine](https://chaomacv.github.io/RAIL-SECURTTY-BENCH/data-engine/): controlled visual synthesis and MLLM-based textual supervision.
- [RailMind implementation](https://github.com/chaomacv/RailMind)

The Data Engine can be visited independently or entered through the project navigation, method, benchmark and resource sections. Its first version provides image placeholders, bilingual explanations and interactive workflow demonstrations. See [the content guide](data-engine/README.md) to add actual images and reviewed examples.
